# LMDA – jaunā vietne

Статический сайт Latvijas Mūsdienu Deju Asociācija. Без сборки и зависимостей: чистые HTML, CSS и JS.

## Структура
- `index.html` – все разделы (Sākums, Sacensības, Licences, Dokumenti, Noteikumi, Kontakti), переключаются через `#якорь`
- `assets/style.css` – оформление (светлая и тёмная тема)
- `assets/app.js` – данные календаря, результатов, документов и логика
- `docs/` – сюда можно положить копии документов (.doc, .xlsx, .pdf)

## Как выложить на GitHub Pages
1. Создайте репозиторий на github.com и загрузите все файлы из этой папки в корень (кнопка Add file → Upload files).
2. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
3. Через минуту сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Для своего домена (например lmda.lv) добавьте файл `CNAME` с именем домена и настройте DNS по инструкции GitHub.

## Как обновлять
- **Новое соревнование:** в `assets/app.js` добавьте строку в массив `CAL` (формат: дата ГГГГ-ММ-ДД, дата текстом, название, тип, жанры).
- **Новые результаты:** добавьте строку в `R26` (или `R25` для архива): название, имя файла, тип.
- **Новый документ:** добавьте строку в `DOCS`.
- **Контакты и цены:** редактируются прямо в `index.html`.

## Файлы документов
Сейчас все ссылки на скачивание ведут на старый сайт `https://www.lmda.lv/mod_info/article_files/`. Чтобы не зависеть от него, скачайте файлы в папку `docs/` и в начале `assets/app.js` замените
`var B="https://www.lmda.lv/mod_info/article_files/";` на `var B="docs/";`
(имена файлов в ссылках уже закодированы, их достаточно оставить как есть).
